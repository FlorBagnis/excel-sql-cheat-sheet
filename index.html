🧠 ¿Cómo piensa SQL?

El orden lógico de ejecución

Aunque vos escribís SELECT primero, el motor de base de datos procesa en este orden mental:

1. FROM

¿En qué tabla o carpeta está la data?

2. WHERE

Descarta lo que no cumple la condición.

3. SELECT

Muestra únicamente las columnas pedidas.
