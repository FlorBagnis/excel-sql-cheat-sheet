## ✨ Características Principales

* 📊 **100 Atajos de Excel Organizados por Categorías:** Navegación, formato, fórmulas, selección y edición estructurados para agilizar el flujo de trabajo diario.
* 🌐 **Selector Bilingüe de Atajos (Español / Inglés):** Alternancia instantánea entre combinaciones de teclado adaptadas al idioma del software (por ejemplo, `Ctrl + N` / `Ctrl + B` para negrita, o `Ctrl + G` / `Ctrl + S` para guardar).
* 🗄️ **Guía Esencial de SQL sin Tecnicismos Rebuscados:** Comandos clave (`SELECT`, `WHERE`, `GROUP BY`, `HAVING`, `JOINs`) explicados en lenguaje claro y cotidiano, con casos de uso prácticos.
* 🧠 **Desglose del Orden Mental de Ejecución en SQL:** Explicación visual de cómo procesa la base de datos una consulta (`FROM ➔ WHERE ➔ GROUP BY ➔ HAVING ➔ SELECT ➔ ORDER BY ➔ LIMIT`) para evitar errores lógicos comunes.
* 🔍 **Buscador Reactivo en Tiempo Real:** Filtrado instantáneo por palabra clave, comando, atajo o descripción mediante JavaScript nativo.
* 📑 **Navegación Fluida por Pestañas:** Interfaz reactiva para alternar entre el módulo de Excel y el módulo de SQL con preservación visual.
* 🌸 **Diseño Moderno & Accesible:** Interfaz estilizada con paleta suave pastel/rosa, tipografía legible y diseño 100% responsivo para computadoras, tablets y celulares.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5 semántico, CSS3 moderno (Tailwind CSS vía CDN, Flexbox, Grid), JavaScript (Vanilla ES6+ reactivo al DOM).
* **Control de Versiones & Deploy:** Git, GitHub, GitHub Pages.
* **Compatibilidad:** 100% ejecutable en cualquier navegador sin descargas, dependencias ni instalaciones.

---

### 🎯 Objetivo del proyecto

El objetivo principal de esta herramienta es **derribar la barrera de entrada al mundo del código y los datos**, facilitando el salto desde planillas de cálculo tradicionales hacia el entendimiento de bases de datos relacionales. 

Aprender una herramienta nueva abre puertas en el camino laboral, y este proyecto fue diseñado para acompañar a quienes dan sus primeros pasos técnicos, aplicando habilidades clave para roles como:

* **Technical Support Specialist / Support Operations**
* **Data & Business Support Analyst**
* **Operations Support / Operations Specialist**
* **Customer Experience & Problem Solving**

El proyecto consolida buenas prácticas de diseño de interfaz de usuario (**UI/UX**), manipulación dinámica del DOM con **JavaScript puro** y la síntesis de conceptos técnicos complejos para transformarlos en herramientas de consulta rápidas, intuitivas y libres de fricción.
